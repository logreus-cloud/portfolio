# portfolio

Сайт-портфолио. Один файл `index.html`, без сборки и зависимостей — шрифт
JetBrains Mono подтягивается из Google Fonts, всё остальное внутри файла.

Дизайн повторяет язык профиля github.com/logreus-cloud: тёмная палитра Primer
(`#0d1117`, рамки `#30363d`, синий `#4493f8`), моноширинный баннер, двухколоночный
профильный layout и карточки репозиториев.

## Посмотреть локально

Открыть `index.html` двойным кликом, либо поднять сервер:

    python -m http.server 8765

и зайти на http://localhost:8765/

## Публикация

Репозиторий развёрнут на GitHub Pages из ветки `main`, папка `/ (root)`:
https://logreus-cloud.github.io/portfolio/

Обновление сайта — обычный пуш в `main`, Pages пересобирает страницу за минуту-две.

## Что править

- Имя, подпись и чипы — блок `.banner` и `<aside class="side">`.
- Проекты — карточки `<article class="repo">`. Бейдж `Public` / `Private` меняется текстом.
- Цвета — переменные в `:root` вверху `<style>`.
